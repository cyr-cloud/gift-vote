# 칭찬 뽑기판

수업 중 대답을 잘한 학생에게 뽑기권을 주고, 5천원 이하 기프티콘이 걸린 뽑기판에서 한 칸씩 뜯게 하는 도구입니다.

## 켜기

`start.bat` 을 더블클릭하거나:

```bash
python server.py
```

브라우저가 `http://localhost:8765` 로 열립니다. 끄려면 검은 창에서 `Ctrl+C`.
Python 3 만 있으면 되고 따로 설치할 패키지는 없습니다.

## 과정 파일

과정 하나가 `courses/<과정이름>.json` 파일 하나입니다. 명단·팀·포인트·당첨내역·뽑기판이 전부 여기에 자동 저장됩니다.

명단은 화면의 **명단 한꺼번에 넣기 · 파일** 버튼으로 한 번에 넣을 수 있습니다.
쉼표·줄바꿈으로 이름을 적거나, `1조: 홍길동, 김철수` 처럼 팀과 팀원을 한 줄에 적거나,
json·csv 파일을 불러오면 됩니다. csv 는 `이름`·`조`(또는 `팀`) 열을 알아서 찾고, 엑셀에서 저장한 한글 csv 도 읽습니다.

새 과정은 화면의 **새 과정** 버튼으로 만들거나, 아래처럼 명단만 적은 json 을 `courses/` 에 넣으면 됩니다. 나머지는 켤 때 채워집니다. 예시: [`examples/course-example.json`](examples/course-example.json)

```json
{
  "name": "온라인 데이터분석 3기",
  "kind": "online",
  "students": ["홍길동", "김철수"],
  "teams": [["1팀", 3], ["2팀", 3]]
}
```

| 필드 | 뜻 |
|---|---|
| `kind` | `online` = 각자 받아 각자 쓰는 상품만 / `offline` = 팀이 나눠 갖는 큰 칸(파인트·먼치킨)도 들어감 |
| `place` | 오프라인 과정 장소 (선택) |
| `note` | 메모. 저장할 때 지워지지 않음 (선택) |
| `teams` | `["1조", 5]` 처럼 이름·인원만, 또는 `{"name":"1조","nick":"코드몬스터","members":["홍길동", …]}` 처럼 조 이름·조원까지 |
| `prizes` / `soloPrizes` | 팀전 / 개인전 상품 목록을 직접 지정 (선택, 없으면 기본 구성) |

> ⚠️ `courses/` 에는 학생 실명이 들어갑니다. 이 저장소는 공개라서 `courses/` 는 `.gitignore` 로 빼 두었습니다.
> 과정 파일은 각자 컴퓨터에만 두고, 절대 커밋하지 마세요. 코드 예시에도 실제 학생 이름 대신 홍길동 같은 가짜 이름을 쓰세요.

## 다른 컴퓨터에서 쓰기

과정 파일도 저장소에 들어 있어서, 어느 컴퓨터에서든 받아서 이어 쓸 수 있습니다.

1. 수업 시작 전: `git pull` — 다른 컴퓨터에서 쓴 뽑기권·포인트·당첨내역을 받아옴
2. 수업 끝난 뒤: `git add courses && git commit -m "수업 기록" && git push`

두 컴퓨터에서 같은 과정을 동시에 켜두지 마세요. 한쪽 기록이 다른 쪽을 덮을 수 있습니다.

## 쓰는 법

- **개인전** — 이름 옆 `+` 로 뽑기권 지급 → 이름 선택 → 판에서 한 칸 뜯기
- **팀전** — 팀 옆 `+` 로 포인트 → 금요일에 **이번 주 1등 발표** → 1등 팀에 뽑기권 1장, 전 팀 포인트 0으로
- 팀전 상품은 팀원 수만큼 곱해서 나갑니다 (`팀 1개` 칸 제외)
- 정산 칸에 뽑기 1회 평균 비용과 한 달 예상 금액이 나옵니다
- 상품 가격·링크는 카카오톡 선물하기에서 확인한 값입니다. 행사에 따라 바뀌니 보내기 전에 한 번 확인하세요
